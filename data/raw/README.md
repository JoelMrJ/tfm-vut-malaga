# Raw data

Esta carpeta contiene los datos originales utilizados por el motor predictivo.

Los datos proceden de Inside Airbnb y corresponden a la ciudad de Málaga.

Archivos utilizados:

```text
listings.csv.gz
calendar.csv.gz
neighbourhoods.geojson
```

Los archivos originales no se incluyen en este repositorio.

Pueden descargarse desde:

https://insideairbnb.com/get-the-data/

Una vez descargados, deben colocarse directamente en esta carpeta antes de ejecutar los notebooks de preprocesamiento.
